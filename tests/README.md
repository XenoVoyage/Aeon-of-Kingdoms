# Aeon of Kingdoms verification

The active source boundary includes the redesign status page, reviewed mood-reference archive, approved Phase 1A production review, owner-approved Phase 1B visual lock, approved production-art contract, the approved Phase 2 landscape foundation, and the implemented Phase 3 entity/movement candidate. Verification proves that these boundaries and files are truthful, local, bounded, and internally consistent; it does not replace separately recorded owner, deployment, rendered, game-feel, browser, or physical-device evidence. The rejected `v2026.8.15` prototype and its old tests remain historical evidence at commit `7f88655`; its public tag and GitHub Release were retired without rewriting history and must not be recreated.

Run the complete dependency-free verification from the repository root:

```sh
node tests/run.js
```

Node.js 20 or newer is used only for local and continuous verification. The suite installs no package and performs no external network request. When the recorded local ImageMagick `convert` executable is available, the Phase 3 asset reproduction check verifies its writable lossless-WebP delegate and compares every regenerated byte. A runner without that optional authoring tool reports one explicit skip while still verifying every committed atlas dimension, byte count, SHA-256, lossless encoding, manifest value, and decoded invariant with Node.
