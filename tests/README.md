# Aeon of Kingdoms verification

The active source boundary includes the redesign status page, reviewed mood-reference archive, approved Phase 1A production review, owner-approved Phase 1B visual lock, approved production-art contract, the approved Phase 2 through Phase 6 foundations, and the frozen documentation-only Phase 7 product-hardening planning contract. Verification proves that these boundaries and files are truthful, local, bounded, and internally consistent; it does not replace separately recorded publication, deployment, rendered, game-feel, browser, network, or physical-device evidence. The rejected `v2026.8.15` prototype and its old tests remain historical evidence at commit `7f88655`; its public tag and GitHub Release were retired without rewriting history and must not be recreated.

Run the complete dependency-free verification from the repository root:

```sh
node tests/run.js
```

Node.js 20 or newer is used only for local and continuous verification. The suite installs no package and performs no external network request. When the recorded local ImageMagick `convert` executable is available, the Phase 3, Phase 4, and Phase 5 asset checks verify its writable lossless-WebP delegate and compare every regenerated byte. A runner without that optional authoring tool reports explicit skips while still verifying every committed dimension, byte count, SHA-256, lossless encoding, manifest value, and decoded invariant with Node.

## Evidence boundary

Static audits and Node/browser-smoke fixtures cannot prove rendered quality, browser cache replacement, live Pages content, a physical device, game feel, or networking. A workflow badge, source version, or changelog heading does not establish a deployment, published tag, or GitHub Release. Record unobserved categories as pending, not passed.
